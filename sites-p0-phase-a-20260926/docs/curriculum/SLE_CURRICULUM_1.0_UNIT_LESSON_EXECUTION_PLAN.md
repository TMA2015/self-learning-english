## Operating sequence
Author first B2-U04 (listening), then audit remaining B2 U01–U10, fill C1 gaps in prerequisite order, then C2, then audit A1–B1. Learner order is different: A1→A2→B1→B2→C1→C2, U01→U10 with advisory prerequisites shown below (no runtime lock). Entry at an appropriate level is allowed. For each Unit: recap relevant prerequisite → explicit teaching and separate worked example → independent guided-to-transfer practice → feedback/repair → integrated Unit transfer and advisory next step. Check actual source outcomes before deciding new material; reuse existing lessons where verified rather than duplicating IDs or evidence. Existing primary order below is an inventory sequence, not a tested optimal lesson order. Within a Unit, validate prerequisites and place teaching before application; final exact learner lesson order is frozen only after source audit. Existing mapped content is NOT automatically complete; all Unit coverage verdicts remain unaudited.
Working inventory: 196 lessons, 1309 activities; 194 primary mapped, 2 unmapped; 42 of 60 have primary lessons. LIVE stays 1.28.1 (176/1224). No runtime version bump, import, deploy, new policy or learner writes. For every lesson keep exact ID, original title, observable outcome, prerequisite, CORE-1–4, independent evidence type, review/asset gates and next action. No arbitrary lesson quota. New slot IDs S01 etc are planning labels only; the B2 listening IDs are reserved proposals subject to collision check at integration. Academic PASS requires independent NotebookLM. Audio blocked until actual aligned rights-cleared playback; free writing/speaking unassessed without validated review.
