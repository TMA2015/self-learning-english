# NotebookLM Reconciliation — Writing Course v2-B

Review verdict: **PASS-WITH-CHANGES**

The high-level Weeks 2–6 order is approved unchanged.

## Four required changes incorporated

1. **Week 5: although becomes optional**
   - core: because / so / but;
   - although is Optional Challenge only;
   - it cannot be required for Guided Practice completion or Main Practice completion.

2. **Pseudo-semantic deterministic grading prohibited**
   - free-form checks are structural/presence only;
   - semantic relevance, argument strength, grammar correctness and CEFR claims are forbidden from keyword/string heuristics.

3. **Week 4 Detail vs Example simplified**
   - learner-facing terms clarified;
   - core Main Practice requires Reason + Supporting Evidence;
   - evidence may be Extra Information or an Example;
   - separate Detail and Example fields are not both mandatory.

4. **Week 6 uses outline fragments**
   - 3–7 words per box;
   - example outline rewritten as notes/fragments;
   - polished sentences are reserved for drafting.

## Additional review improvements accepted

- learner-facing terminology simplified:
  - Point -> My Opinion / Main Idea
  - Relevance -> Sticking to the Topic
  - Linker -> Connecting Word
  - Detail -> Extra Information
- Week 5 optional collapsible sentence starters;
- Week 2 Off-Topic Spotter explanation;
- Week 6 outline-stack preview may be used as a visual bridge, but must not auto-write a paragraph.
