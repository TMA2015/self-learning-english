# NotebookLM Reconciliation — Writing Course v2-C

Review verdict: **PASS-WITH-CHANGES**

High-level Weeks 7–12 order remains unchanged.

## Four required changes incorporated

1. **Week 7 Closing Thought becomes optional**
   - renamed conceptually to Optional Wrap-Up;
   - short paragraphs may end naturally without a separate closing sentence;
   - completion cannot require it.

2. **Week 12 Guided Practice becomes optional**
   - reframed as Optional Self-Readiness / Planning Scratchpad;
   - unscored;
   - skippable;
   - cannot block Main Practice.

3. **Weeks 9–10 fallback drafting simplified**
   - fallback learner-authored draft: one simple 40–60 word paragraph;
   - optional one-click Sample Student Draft is allowed for practice.

   Safety reconciliation:
   - Sample Student Draft is fixed practice text for a separate prompt;
   - clearly labeled not learner-owned;
   - not a model answer to the current Main Practice task;
   - does not enter the learner’s own writing portfolio;
   - proficiency weight remains 0.

4. **Model and diff labels tightened**
   - all post-submission models use:
     **One Possible Sample Response (Not the Only Way)**
   - automated Before/After helpers report surface facts only;
   - never claim improvement, correctness, style quality, or proficiency.

## Optional review improvements accepted

- optional Week 8 paragraph-bridge visual;
- Week 9 interactive checklist toggles may be implemented;
- a future My Writing Growth portfolio is academically useful but is NOT required for WCV2-C implementation and may be deferred.
